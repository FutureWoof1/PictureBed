# 安全验证功能说明 🔐

## 功能概述

本应用已添加安全验证功能，只有通过密码验证的用户才能编辑内容，其他访客只能查看。

---

## 🎯 功能特性

### 1. 只读模式（默认）
- ✅ 可以查看所有内容
- ✅ 可以浏览照片
- ✅ 可以查看时光轴
- ❌ 无法添加新内容
- ❌ 无法编辑现有内容
- ❌ 无法删除内容
- ❌ 无法导入/导出数据

### 2. 编辑模式（需验证）
- ✅ 所有只读模式的功能
- ✅ 可以添加甜蜜日常
- ✅ 可以添加纪念日
- ✅ 可以编辑现有内容
- ✅ 可以删除内容
- ✅ 可以导入/导出数据
- ✅ 可以刷新云端数据

## 🔧 配置密码

### 方法一：使用配置文件（推荐）

1. 复制配置文件示例：
```bash
cp config.example.js config.js
```

2. 编辑 `config.js`，修改密码：
```javascript
// 编辑密码（用于保护内容编辑功能）
window.EDIT_PASSWORD = 'your_custom_password';  // 修改为你自己的密码
```

3. 保存文件并刷新页面

### 方法二：直接修改 main.js（不推荐）

在 `main.js` 文件中找到 CONFIG 对象，修改 `editPassword`：
```javascript
const CONFIG = {
    // ...其他配置
    editPassword: 'your_custom_password'  // 修改这里
};
```

⚠️ **重要提示**：
- 默认密码是 `love2022`，强烈建议修改！
- 不要使用过于简单的密码
- 不要将密码告诉不信任的人

## 📖 使用说明

### 首次访问（只读模式）

1. 打开网页后，右上角会显示橙色的"只读模式"提示框
2. 提示框包含一个"登录编辑"按钮
3. 所有编辑相关的按钮（添加、编辑、删除）都会被隐藏

### 登录编辑

1. 点击右上角的"登录编辑"按钮
2. 在弹出的验证框中输入密码
3. 点击"验证"按钮
4. 如果密码正确：
   - 提示"验证成功！现在可以编辑内容了"
   - 只读模式提示框消失
   - 所有编辑按钮显示
   - 页脚出现"退出登录"按钮
5. 如果密码错误：
   - 显示"密码错误，请重试"
   - 可以重新输入

### 退出登录

1. 滚动到页面底部
2. 点击红色的"退出登录"按钮
3. 确认退出
4. 返回只读模式

## 🔒 安全机制

### 会话管理
- 验证状态保存在浏览器的 `sessionStorage` 中
- 有效期：1小时
- 关闭浏览器后自动失效
- 需要重新验证

### 密码存储
- 密码存储在配置文件中（明文）
- 仅在客户端验证
- 不会发送到服务器
- 适合个人使用或小范围分享

### 隐藏元素
使用 CSS 类 `readonly-mode` 控制：
- 添加按钮：`.add-btn`
- 编辑按钮：`.memory-edit`, `.anniversary-edit`
- 删除按钮：`.memory-delete`, `.anniversary-delete`
- 数据管理按钮：`#refreshDataBtn`, `#exportDataBtn`, `#importDataBtn`

## 🔧 技术实现

### 核心类：AuthManager

```javascript
class AuthManager {
    constructor()           // 初始化，检查会话状态
    checkAuth()            // 检查认证状态
    authenticate(password) // 验证密码
    logout()               // 退出登录
    setReadonlyMode()      // 设置只读模式
    setEditMode()          // 设置编辑模式
    showAuthModal()        // 显示验证框
    closeAuthModal()       // 关闭验证框
}
```

### 工作流程

1. **页面加载**
   - 创建 `AuthManager` 实例
   - 检查 `sessionStorage` 中的认证状态
   - 如果已认证且未过期 → 编辑模式
   - 否则 → 只读模式

2. **用户登录**
   - 点击"登录编辑"按钮
   - 显示验证模态框
   - 输入密码并提交
   - 验证密码是否正确
   - 保存认证状态到 `sessionStorage`
   - 切换到编辑模式

3. **用户退出**
   - 点击"退出登录"按钮
   - 清除 `sessionStorage` 中的认证状态
   - 切换到只读模式

## ⚠️ 注意事项

### 安全性
1. **这不是高安全性的验证方式**
   - 密码存储在客户端
   - 仅适合个人使用或小范围分享
   - 不适合存储敏感信息

2. **密码保护建议**
   - 不要在公共场所输入密码
   - 不要将密码告诉不信任的人
   - 定期更换密码

### 兼容性
- 需要浏览器支持 `sessionStorage`
- 需要浏览器支持 ES6 语法
- 推荐使用现代浏览器（Chrome、Firefox、Safari、Edge）

### 数据安全
- 只读模式下数据仍然存储在浏览器中
- 技术人员可以通过开发者工具查看数据
- 如需更高安全性，建议使用后端验证

## 🎉 使用场景

## 🐛 故障排除

### 问题1：忘记密码
**解决方法**：
1. 打开浏览器开发者工具（F12）
2. 在控制台输入：`sessionStorage.clear()`
3. 刷新页面
4. 修改 `config.js` 中的密码
5. 重新登录

### 问题2：验证框无法关闭
**解决方法**：
1. 刷新页面
2. 如果问题持续，清除浏览器缓存

### 问题3：登录后仍然是只读模式
**解决方法**：
1. 检查浏览器控制台是否有错误
2. 确认密码是否正确
3. 清除 `sessionStorage` 并重新登录
4. 检查 `main.js` 是否正确加载
