# 📱 多端同步使用指南

## 🎯 功能说明

配置阿里云 OSS 后，你的甜蜜相册数据将自动同步到云端，实现多设备访问和数据共享！

### ✨ 主要特性

- ✅ **自动同步**：添加/删除内容时自动上传到 OSS
- ✅ **多端访问**：不同设备打开网页都能看到最新数据
- ✅ **实时更新**：点击"刷新数据"按钮获取最新内容
- ✅ **数据安全**：数据存储在你的 OSS 上，完全私密
- ✅ **离线可用**：本地也会缓存数据，离线也能查看

---

## 🔧 配置步骤

### 1. 配置 OSS

编辑 `config.js` 文件：

```javascript
const OSS_CONFIG = {
    region: 'oss-cn-beijing',           // 你的 OSS 区域
    accessKeyId: 'YOUR_ACCESS_KEY_ID',  // 你的 AccessKey ID
    accessKeySecret: 'YOUR_ACCESS_KEY_SECRET', // 你的 AccessKey Secret
    bucket: 'YOUR_BUCKET_NAME',         // 你的 Bucket 名称
    uploadDir: 'sweet-album/',          // 图片上传目录
    dataFile: 'sweet-album/data.json'   // 数据文件路径（用于多端同步）
};
```

### 2. 设置 OSS 跨域规则

在阿里云 OSS 控制台设置跨域规则（CORS）：

1. 进入你的 Bucket 管理页面
2. 找到「数据安全」→「跨域设置」
3. 添加规则：

```
来源：*
允许 Methods：GET, POST, PUT, DELETE, HEAD
允许 Headers：*
暴露 Headers：ETag, x-oss-request-id
```

### 3. 设置 Bucket 权限

**重要**：为了安全，建议设置为「私有」，然后通过签名 URL 访问。

但为了简化使用，你也可以：
- 将 Bucket 设置为「公共读」
- 或者配置 Bucket Policy 允许读取 `sweet-album/` 目录

## 📖 使用说明

### 首次使用

1. **配置 OSS**：按照上面的步骤配置 `config.js`
2. **打开网页**：第一次打开时会自动创建云端数据文件
3. **添加内容**：添加的内容会自动同步到云端

### 多设备访问

1. **其他设备**：在其他设备上打开网页（使用相同的 OSS 配置）
2. **自动加载**：页面会自动从云端加载数据
3. **查看内容**：可以看到所有设备添加的内容

### 刷新数据

如果你在一个设备上添加了内容，在另一个设备上：

1. 点击页面底部的 **「刷新数据」** 按钮
2. 数据会从云端重新加载
3. 就能看到最新的内容了！

## 🔒 安全建议

### 1. 保护配置文件

- ❌ **不要**将 `config.js` 提交到公开的 Git 仓库
- ✅ 已在 `.gitignore` 中排除
- ✅ 只分享给信任的人

### 2. OSS 权限设置

- 建议使用子账号 AccessKey
- 只授予必要的权限（读写指定 Bucket）
- 定期更换 AccessKey

### 3. 数据隐私

- 数据存储在你自己的 OSS 上
- 只有拥有 AccessKey 的人才能访问
- 建议设置 Bucket 为私有

## ❓ 常见问题

### 1. 为什么看不到其他设备添加的内容？

**解决方法**：
- 点击「刷新数据」按钮
- 检查 OSS 配置是否一致
- 查看浏览器控制台是否有错误

### 2. 提示"保存失败"？

**可能原因**：
- OSS 配置错误
- 网络连接问题
- OSS 跨域规则未设置

**解决方法**：
- 检查 `config.js` 配置
- 检查 OSS 跨域设置
- 查看浏览器控制台错误信息

### 3. 数据会丢失吗？

**不会！**
- 数据同时保存在本地和云端
- 即使网络断开，本地数据仍然可用
- 恢复网络后会自动同步

### 4. 如何关闭云端同步？

如果不想使用云端同步：
- 删除或清空 `config.js` 中的 OSS 配置
- 数据将只保存在本地浏览器

## 📊 数据存储说明

### 本地存储（LocalStorage）

- 用于缓存数据，提高访问速度
- 即使离线也能查看内容
- 清除浏览器数据会丢失

### 云端存储（OSS）

- 数据文件：`sweet-album/data.json`
- 包含所有甜蜜日常和纪念日数据
- 永久保存，不会丢失

### 图片存储（OSS）

- 存储路径：`sweet-album/图片文件名`
- 每张图片独立存储
- 通过 URL 引用
